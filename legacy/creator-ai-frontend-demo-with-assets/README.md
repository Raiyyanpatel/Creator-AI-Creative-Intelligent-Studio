# Creator AI Frontend Demo

Open `demo/index.html` in a browser.

Demo routes:
- #onboarding
- #home
- #insights
- #create
- #editor
- #profile

No backend. All data and interactions are mocked.

Use DESIGN.md as the implementation/design brief for an AI coding agent.


## Generated visual assets

The `demo/assets/` folder contains 16 cropped images generated as a single visual asset sheet and then split into individual reusable assets.

They are wired into:
- Home hero and project cards
- Insights trend cards
- Create cards
- Editor preview
- Profile/avatar
- Onboarding
